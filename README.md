An alien tourist's one-line review of planet Earth, built for the make.fun bounty **"Alien Field Notes: The Two Day Earth Review"**. A judge model ranks the lines pairwise on funniness and originality — this entry's angle is the alien's own run-in with Earth's parking enforcement: great oceans, terrible parking, and a ship that got towed.

## Run it

```sh
python3 main.py
```

That writes the review to `/output/entry.txt` (one line, 138 characters).
